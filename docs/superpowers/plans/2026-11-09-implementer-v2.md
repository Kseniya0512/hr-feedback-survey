# Implementer v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Заменить анкету внедрения на пилотную, не потеряв старые данные и не меняя участников.
**Architecture:** Версионированная схема, общие условные вопросы/матрица, чистые расчёты, существующие адаптеры хранения, новые секции текущей аналитики.
**Tech Stack:** HTML/CSS/vanilla JS, Node test runner, существующий Playwright.
**Spec:** docs/superpowers/specs/2026-11-09-implementer-v2-design.md

## Global Constraints
- Вопросы и варианты полностью соответствуют заданию; участники не меняются.
- Новая анкета 7 блоков, 22 нумерованных вопроса; матрица — один вопрос с шестью строками.
- Сохраняются локальный запуск, дизайн, экспорт, API авторизация; добавленные метаданные не персональные.
- Старая версия и черновики читаются отдельно, не переосмысляются.

## Review Focus
- Коллизия новых и старых i1…i20: проверять по questionnaireVersion.

- Полузаполненная матрица восстанавливается, но не проходит отправку.
- Максимум три/несовместимые варианты не обходятся импортом.
- Доля респондентов отличается от доли уникальных initiativeId.
