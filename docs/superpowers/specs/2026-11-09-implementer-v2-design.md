# Обновление анкеты команды внедрения

Изменяется существующее приложение, сохраняются оформление, навигация, локальный/API режим, экспорт/импорт и участники (их схема зафиксирована тестом без изменений).

Новая анкета: блоки 0–6, 0.1/0.2 и вопросы 1–20 по заданию. Матрица №4 содержит шесть самостоятельных строк 1–5/na. №7 получает только реальные сложности из №6; №9 виден при увеличении затрат. №14–16 видны на всех стадиях кроме подготовки. №17 требует явной отметки о запуске новых правил (служебный флажок после выбора стадии), поскольку стадия не доказывает запуск. Все отрицательные/ещё не применявшиеся исключающие варианты множественного выбора взаимоисключаются; №19 максимум три. Поле «Другое» в №3 добровольное. Скрытые/потерявшие применимость ответы удаляются из текущего черновика и исключаются из расчётов/экспорта даже для импортированных записей.

Выбрано версионирование схемы, а не преобразование старых ответов с другим смыслом: новые implementer записи содержат questionnaireVersion:2; отсутствие версии у implementer означает старую v1. Участники сохраняют прежний формат. Старая анкета сохраняется только как схема для чтения истории, не новый маршрут. Старые завершённые ответы остаются читаемыми, доступны экспорт/аналитика архива, не входят в новые метрики. Ключи черновиков новой implementer версии отделены; прежние черновики можно скачать, они не перезаписываются.

Аналитика новой анкеты делится на четыре направления из задания. Специальные ответы исключены из средних. Недостаток данных отображается текстом. Добавляются стадия/роль как фильтры команды; при применении этих фильтров участники не включаются в выборку. Инициативы идентифицируются необязательным initiativeId (имя не ключ). Отдельная агрегация фактических результатов: последний ответ каждой инициативы по времени UTC (при равенстве ID ответа), без initiativeId не участвуют. Каждая метрика показывает числитель и собственный знаменатель оцениваемых ответов/инициатив, «рано»/«нет информации» исключаются. Это описание мнения респондентов, не подтверждённый аудит инициатив.

Проверки: старые/новые данные вместе, импорт/экспорт matrix+other+version+initiativeId, все пять стадий и флажок запуска, pruning при изменении зависимостей, матрица и max3, полные маршруты обеих аудиторий, восстановление черновика, мобильная ширина.
